Voice chat in the browser.

Join a Simple Voice Chat Minecraft server straight from your browser. No mod, no launcher install, no extra account – one link and you are in the call.

Open voice chat Read the docs

Works in Chrome, Edge, Firefox and Safari on desktop. Microphone access is required.

What you get

Everything the mod can do, without the installation.

No install for players

Browser players join with a link. Nothing to download, nothing to configure.

Real 3D audio

Positional sound with distance attenuation – the same falloff the mod uses.

Real SVC groups

Create and join real Simple Voice Chat groups, including password-protected ones.

Invite codes and QR

/voice link creates a short-lived code and a QR card in game.

Push-to-talk and mixer

Hold to talk, per-player volume, mute and deafen – synced with the mod.

Server-side bridge

The plugin translates between WebRTC and Simple Voice Chat. Audio stays on your server.

How it works

The server runs Simple Voice Chat plus the SimpleVoiceChatWeb plugin. The plugin bridges WebRTC audio from the browser into SVC, so a browser participant is a full player: positional audio, groups, mute and deafen, exactly like with the mod.

For server owners

Three steps and your players can listen in without the mod.

  1. 1

    Install

    Install Simple Voice Chat and the SimpleVoiceChatWeb plugin on your Paper or Spigot server.

  2. 2

    Generate an invite

    Run /voice link in game. The player gets a code and a QR card.

  3. 3

    Share

    Share the link or let them scan the QR – the browser client opens with the code filled in.

Quick start guide

Have an invite code?

Enter it here, or open the link you were given – the code is filled in automatically.

Codes are single-use and expire after 5 minutes.
